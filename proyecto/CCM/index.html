Cálculo de un Centro de Control de Motores

En esta sección se calcula una ubicación ideal para un centro de control de motores, aumentando la eficiencia y reduciendo las perdidas de potencia que se pueden presentar en el sistema al momento de su funcionamiento, los CCM se pueden obtener con sus especificaciones para los motores necesarios, es completamente normal que no se siga la normativa para obtener la eficiencia del centro, en este caso, yo demostrare como seleccionar su ubicación y comprender los CCM desde un punto de vista critico y riguroso.

Para el correcto cálculo, es imprescindible comprender las dimensiones y realizar una visualización completa del entorno en el cual se instalara el centro de control de motores, para este caso se tiene el siguiente plano:

Con el plano anterior ya podemos comenzar a comprender principalmete como seria su implementación, sin embargo, tambien debemos conocer las caracteristicas termicas del lugar, las estructuras en su interior, su materialidad y evidentemente las dimensiones de los motores y del recinto donde se instalara el CCM. En este caso, se instalara el CCM en la sala de procesos, la cual tiene las siguientes dimensiones: $$Largo= 40\space m$$ $$Ancho = 30\space m$$

El cliente informa que necesita 16 bombas sanitarias para un proceso de leche en la planta, esto convierte a nuesto analisis mucho mas cuidadoso, ya que las circustancias de las bombas seran sanitarias y por lo tanto, se deben minimizar aún mas los errores, y aumentar la eficiencia del CCM para una menos contaminación del producto en caso de falla. El cliente informa la potencia de los motores que seran todo iguales y las ubicaciones ideal de los motores para la planta y el proceso conveniente.

Ya que tenemos la ubicación, debemos definir una esquina del recinto (idealmente la superior) con las coordenadas $X, Y = 0,0$ y asi definir las coordenas de los motores en el plano cartesiano, para asi definir las distancias sumarias entre cada motor.

Con las coordenadas definidas, se procede a dimesionar en el plano las ubicaciones, saltamos el primer motor mas acercado al muro para equilibrar el centro de masa, y procedemos a definir las distancias en X y Y de cada motor al punto (0,0), para asi obtener las siguientes distancias:

Una vez que realizamos las distancias, tomamos el momento eléctrico para calcular la ubicación mediante el siguiente cálculo: $$HP_T\space\cdot\space L_e=\sum_{i=1}^{n}HP_T\space \cdot\space \sum_{i=1}^{n}L_e$$ Para esta aplicación, se tiene:

    • Por lo tanto: $$HP_T\space\cdot\space L_{ex}=\frac {HP_1\cdot L_{x1}+HP_2\cdot L_{x2}+HP_3\cdot L_{x3} +HP_4\cdot L_{x4}+...}{HP_T}$$
